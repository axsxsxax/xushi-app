# 序时

浅蓝海洋与花草主题的生活规划与专注管理应用。电脑上可双击 `index.html` 用浏览器打开；iPhone 版通过 HTTPS 网站在 Safari 中添加到主屏幕。无需安装开发依赖。

## 页面

1. **计时活动**：自建标签；正计时、倒计时、50/10 循环；独行与并行；关联待办；按起止时间补记活动；按标签查看和删除计时记录；完成后的小鱼按计时时长变化大小。“今日航线”推荐下一件重要的事，并显示连续行动天数。
2. **待办事项**：四象限优先级、可选提醒、每日完成数、喝水记录；完成后在海洋里加入水母。
3. **运动健康**：身高单独保存，按日期记录体重并查看历次曲线；还可记录饮食、运动和经期。
4. **心情日记**：记录每日心情与文字日记。
5. **统计总结**：本周、本月、今年的时间饼图、趋势、海洋、已完成待办与心情概览，以及阶段总结。
6. **日历**：手动添加日程，或导入 `.ics` 日历文件。
7. **设置**：调整 50/10 时长、喝水目标与提醒间隔，导出或导入 JSON 备份。

浏览器提醒仅在页面打开时工作；此版本不提供阻止打开其他软件的功能。所有个人记录只保存在当前设备、当前浏览器中，不会自动上传到 GitHub。其他人打开同一网址只能看到自己浏览器中的记录；能使用同一设备和浏览器的人可以查看本地记录。建议定期使用“设置 > 导出备份”，不要公开分享备份文件。本地文件、GitHub Pages 网站和 iPhone 主屏幕 App 的数据不会自动同步，迁移时请导出再导入。

## iPhone 安装

GitHub Pages 从项目根目录 `/(root)` 发布。发布后，在 iPhone Safari 打开 HTTPS 网址，点“分享”>“添加到主屏幕”。首次联网打开并加载完成后，应用文件会被缓存，可离线打开。具体发布步骤见 `部署到GitHubPages.md`。

## 文件

- `index.html`、`styles.css`、`theme.css`、`app.js`：本应用源程序。
- `sea-garden.svg`、`app-icon.svg`：本应用的原创界面图案与图标源图。
- `sw.js`、`manifest.webmanifest`、`app-icon-*.png`：主屏幕安装与离线缓存。
- `dev-server.mjs`：电脑本机预览服务器，运行 `node dev-server.mjs`。
- `icons/`：Lucide 图标，许可证见 `vendor/lucide-LICENSE.txt`。
- `vendor/ical.min.js`：ical.js 日历解析器，许可证见 `vendor/ical-LICENSE.txt`。
- `使用说明.md`：详细操作说明。
- `软著申请准备.md`：软件著作权登记材料清单。
